# Ссылка на отзыв и настройки салона (2026-09-29)

## Ссылка на отзыв после визита

Раньше при завершении визита создавался одноразовый `review_token`, но ссылку клиенту никто не
отправлял — оставить отзыв было нельзя.

- Событие `record.updated` с `change = "completed"` → задача `notify_client_review`
  (`workers/tasks/notify.py`): клиенту в Telegram «Дякуємо за візит!» со ссылкой на форму отзыва.
- Ссылка — `{ADELANTE_BOOKING_BASE_URL}/{slug}/review?token=<review_token>` (`Settings.review_url`).
  Форму показывает публичный сайт записи.
- Токен в outbox не кладётся (событие уходит и в WebSocket админки) — задача читает его из записи.
  Отзыв уже оставлен (токена нет) или клиент не привязан к боту — сообщения нет. Дубли отсекаются
  по `event_id`, как у остальных уведомлений.
- `GET /api/booking/{slug}/reviews/{token}` — данные для формы: `salon_name`, `master_name`,
  `services`, `visit_at`. Использованный или чужой токен — `404`.
- `POST /api/booking/{slug}/reviews` — без изменений (токен одноразовый).

## Налаштування салону

Хранение: название — `salons.name` в Master DB (его видят бот, сайт записи, переключатель салона);
остальное — JSON в таблице `settings` шарда, ключи `salon_info` и `salon_schedule`
(`app/services/salon_settings.py`). Миграция не нужна — таблица была и пустовала.

| Эндпоинт | Что |
| --- | --- |
| `GET /settings/salon` | Інформація про салон |
| `PATCH /settings/salon` | Изменённые поля; пустая строка или `null` — очистить (кроме `name`) |
| `GET /settings/schedule` | Графік роботи салону; `configured: false` — ещё не заполняли |
| `PUT /settings/schedule` | Весь график: все семь дней недели |
| `GET /api/booking/{slug}/salon` | Публичная карточка: контакты и график (без юридического названия и даты открытия) |

- Права: администратор и суперюзер; мастеру `403`.
- Изменения — в журнале (`entity = "settings"`, «Інформація про салон» / «Графік роботи салону»),
  график в журнале — текстом «09:00–20:00» / «вихідний».
- График салона пока ни на что не влияет: слоты и рабочее время в Розкладе считаются по графикам
  мастеров.
