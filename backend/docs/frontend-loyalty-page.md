## 1. Что показано в видео (Altegio)

### 1.1. Хаб «Лояльність»
Пункт «Лояльність» в боковом меню. Сверху баннер «Залучайте нових клієнтів…», ниже 4 карточки
одна под другой: иконка, заголовок, описание в 2–3 строки, справа кнопка «Налаштування».

| Карточка | Описание (текст с экрана) | Куда ведёт |
|---|---|---|
| Карти лояльності, знижки та Кешбек | Підвищуйте лояльність клієнтів за допомогою повторних знижок, кешбеку та бонусів. Запропонуйте знижку на перший візит або реферальну програму, щоб заохотити клієнтів розповідати про вас. | Список «Акції» |
| Сертифікати | В середньому клієнти використовують тільки 60% проданих сертифікатів, інші 40% так і залишаються невикористаними після придбання. А кожен четвертий проданий сертифікат означає нового клієнта | «Типи сертифікатів» |
| Абонементи | Членство заохочує повторні відвідування та допомагає оптимізувати час персоналу, підвищуючи рівень заповнюваності. | «Типи абонементів» |
| Депозити на рахунках клієнтів | Клієнтські рахунки дозволяють лояльним клієнтам здійснювати передоплату за послуги, забезпечуючи повторні відвідування. Заохочуйте поповнення рахунку, щоб збільшити утримання клієнтів і прибуток. | «Типи рахунків» |

Внизу страницы виден заголовок «Допомога з налаштуванням» — содержимое в видео не показано.

### 1.2. Акції (кнопка 1)
- Список: Назва (ссылка), Тип («Фіксована знижка»), Додана (дата). Кнопка «+ Додати акцію».
- Редактор акции, секциями-карточками:
  - Назва акції.
  - Тип промоції: Знижки / Бонуси (плитки с галочкой).
  - Види знижок: Фіксована (бейдж «Підходить для реферальної програми»), Накопичувальна від
    кількості візитів, Накопичувальна від суми, Знижка за умови.
  - Тип знижки: % від суми / фіксована сума. Значення знижки.
  - Послуги, які можна оплатити зі знижкою (мультиселект, «Всі послуги»).
  - Товар, який можна оплатити зі знижкою («Не для товарів»).
  - За якими картками діє акція (чекбоксы типов карт + «Вибрати всі»).
  - У яких філіях діє акція (чекбоксы салонов + «Вибрати всі»).
  - «Видалити лояльність» / «Зберегти».

### 1.3. Типи сертифікатів (кнопка 2)
- Вкладки Активний / Архів, поиск по названию, «+ Створити».
- Группировка по категориям («Без категорії · 8 типи…»), строки перетаскиваются.
- Колонки: Назва (+ «Всі філії» / «Немає локацій»), Вартість ₴, Термін дії
  («Безліміт», «30 днів», «1 рік», «до 31.03.2024»), Випущено (ссылка), иконка-меню.
- Редактор: Назва, Номінал (после выпуска read-only), Тип списання (багаторазове / одноразове),
  Категорія, Обмеження застосування (будь-які товари та послуги / деякі послуги без товарів +
  выбор), Обмеження терміну дії (без обмеження / фіксований від продажу N днів|місяців /
  до дати), Дозволити продаж без коду, В яких філіях можна змінювати баланс і термін,
  Доступність для продажу онлайн, Діє в філіях. Кнопка «Зберегти».

### 1.4. Типи абонементів (кнопка 3)
- Вкладки «Активні типи» / «Архів типів», поиск, «+ Додати тип абонемента».
- Колонки: Назва, Випущено, иконка «копировать». Пагинация (5 на странице).
- Редактор (вкладки Налаштування / Повідомлення):
  - Назва.
  - Послуги: Баланс абонемента (загальний / роздільний), Кількість, список услуг, «+ Додати послугу».
  - Загальні: Вартість, Тривалість (N + день/місяць), Активувати (при першому візиті / …),
    Автоматично активується (так/ні) через N днів, В яких місцях користуватися,
    Дозволити заморожувати (так/ні) + Період (0 — без обмежень), Діє у філіях
    («Додати всю мережу», «Скидати вибір»).
  - Флаги: продаж без коду, перерахунок вартості послуги при оплаті абонементом,
    доступний для онлайн-продажу.
  - «Архівувати» / «Зберегти налаштування».

### 1.5. Типи рахунків (кнопка 4)
- Таблица: Назва, Відкрито рахунків. «+ Додати тип рахунку».
- Модалка «Змінити тип облікового запису»: Назва, Можна користуватися в філіях (+ вибрати /
  скасувати всі), Оплата в кредит (дозволити), Дозволений від'ємний баланс ₴. Видалити / Зберегти.

## 3. Расхождения с видео

1. **Акції.** Отдельной сущности «акция» нет. У нас скидки живут в типе карты (уровни:
   накопительная по сумме или визитам, фиксированная) и в личной скидке клиента. Нет:
   акций без карты, «знижки за умови», ограничения скидки по услугам и товарам, привязки
   одной акции к нескольким типам карт, промо-типа «Бонуси» вне кешбэка.
2. **Сертификаты.** В шаблоне нет: типа списания (одноразове/багаторазове), категорий
   и ручной сортировки по группам (есть `sort_order`), срока «до даты» (только `valid_days`),
   ограничения по товарам, «продаж без коду», «продаж онлайн», салонов действия и салонов,
   где можно менять баланс. Нет счётчика «Випущено» в ответе списка шаблонов.
   Архив = `is_active=false`, его можно сделать без бэкенда.
3. **Абонементы** — нет ничего: ни модели, ни API, ни продажи, ни списания при оплате.
   Это отдельная бэкенд-задача уровня `certificates.md`.
4. **Депозиты.** Типов счетов, кредитного лимита и ограничения по салонам у нас нет
   **по решению заказчика** (счёт один на сеть, лимита долга нет). Экран «Типи рахунків»
   не на что повесить.

## 4. Решения (2026-11-11)

| # | Решение |
|---|---|
| 1 | «Акції» нужны отдельной сущностью, как в Altegio — **бэкенд-задача** |
| 2 | Сертификатам добавить: категорії, «до дати», товари (`certificates.md`, раздел 11) — **бэкенд-задача**. Одноразове списання не делаем. «Продаж без коду», выбор філій и онлайн-продаж не нужны (платёжную систему не подключаем) |
| 3 | Абонементы делаем — **бэкенд-задача** |
| 4 | Депозиты: один счёт на клиента на сеть, как сейчас. Типов счетов нет. Бэкенд не трогаем |
| 5 | Реестр сертификатов и балансы клиентов **переносим** из Фінансів в «Лояльність», в Фінансах их больше нет |
| 6 | Баннер и «Допомога з налаштуванням» не нужны |
| 7 | «Лояльність» и «Сертифікати» убираются из Налаштувань, остаются только на новой странице |
| 8 | Раздел видит только суперюзер (как сейчас вкладки в настройках) |

Порядок работ: **этап 1** — фронт без бэкенда (раздел 5); **этап 2** — бэкенд: акции,
абонементы, поля сертификатов (отдельная спека); **этап 3** — фронт к этапу 2.

## 5. Этап 1: фронтенд без доработок бэкенда

1. **Роут `/loyalty`** и пункт меню «Лояльність» в `widgets/app-layout/menu.tsx` (после
   «Послуги»). Раздел доступа `loyalty` в `shared/auth/access.ts` — суперюзер.
2. **Хаб** — 4 карточки по 1.1: иконка, заголовок, описание, кнопка «Налаштування».
   Кнопка 1 → `/loyalty/cards`, 2 → `/loyalty/certificates`, 4 → `/loyalty/deposits`.
   У «Абонементи» кнопка неактивна с подписью «Скоро».
3. **`/loyalty/cards`** — перенос `LoyaltyTab` (типы карт + бонусные правила) без изменения логики.
4. **`/loyalty/certificates`** — две вкладки: «Типи сертифікатів» (перенос `CertificatesTab` +
   подвкладки Активні / Архів по `isActive` + поиск по названию на клиенте) и «Видані
   сертифікати» (перенос `CertificatesRegistryTab` из Фінансів).
5. **`/loyalty/deposits`** — перенос `ClientBalancesTab` из Фінансів.
6. **Убрать** вкладки «Лояльність» и «Сертифікати» из Налаштувань, «Рахунки клієнтів» и
   «Сертифікати» из Фінансів. Старые ссылки (`/settings?tab=loyalty|certificates`,
   `/finances?tab=balances|certificates`) редиректят на новые страницы.
7. Хлебные крошки «Лояльність › …» на подстраницах.
