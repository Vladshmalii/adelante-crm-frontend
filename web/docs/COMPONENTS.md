# Компоненты Ant Design для страниц Adelante CRM

Какие компоненты используем для страниц из [FEATURES.md](./FEATURES.md) и чего в библиотеке нет.

Проверено по установленным пакетам (`web/node_modules`), а не по памяти:

- `antd` **6.6.5**, 64 компонента;
- `@ant-design/pro-components` **3.1.14-7** (beta), ~170 экспортов;
- `@ant-design/icons` **6.3.4**.

Пометка **⚠** — место, где я не уверен: решение надо проверить прототипом до того, как на нём
строить страницу. Все такие места собраны в разделе «Где не уверен».

## 1. Общие паттерны

Один и тот же тип экрана везде собираем одинаково, чтобы страницы не расходились.

| Паттерн                         | Компоненты                                                                                       | Комментарий                                                                                                                                                                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Каркас приложения               | `ProLayout` (pro)                                                                                | Уже в `widgets/app-layout`: меню, свёртка, шапка, аватар, переключатель салона                                                                                                                                                                                  |
| Страница                        | `PageContainer` (pro)                                                                            | Заголовок, подзаголовок, крошки, вкладки (`tabList`), кнопки справа (`extra`)                                                                                                                                                                                   |
| Вкладки страницы в URL          | `PageContainer.tabList` + search-параметр роутера                                                | Огляд, Фінанси: `?tab=` валидируется zod, как `pages/clients`                                                                                                                                                                                                   |
| Список с фильтрами и пагинацией | `ProTable` (pro)                                                                                 | Колонки с `valueType` (`money`, `date`, `dateTime`, `select`, `digit`), `toolbar.search`, `options` (плотность, выбор колонок, обновить), `rowSelection`. Состояние в URL, данные через TanStack Query (`dataSource` + `pagination`), а не встроенный `request` |
| Фильтры над таблицей            | `LightFilter` (pro) — компактные, или `QueryFilter` (pro) — форма с кнопкой «Показати»           | В старом UI везде была форма «Параметри фільтрації» с кнопкой. | Создание / редактирование       | `ModalForm` или `DrawerForm` (pro) + поля `ProForm*`                                             | Одна форма на сущность с режимом create/edit вместо пар Add/Edit по 300 строк. Валидация через `rules`                                                                                                                                                          |
| Большая форма сбоку             | `DrawerForm` (pro)                                                                               | Запись в календаре (в старом UI — правая панель)                                                                                                                                                                                                                |
| Карточка сущности (просмотр)    | `Drawer` + `ProDescriptions` / `Descriptions`                                                    | Клиент, сотрудник, операция, чек, документ                                                                                                                                                                                                                      |
| Карточка с вкладками            | `Drawer` + `Tabs`                                                                                | Клиент (Інформація / Історія), запись в Огляді (Запис / Фінанси / Аудит / Медіа)                                                                                                                                                                                |
| Подтверждение удаления          | `Popconfirm` в строке, `modal.confirm` из `App.useApp()` для крупных действий                    |                                                                                                                                                                                                                                                                 |
| Уведомления о результате        | `message` / `notification` из `App.useApp()`                                                     | `AntApp` уже подключён в `app/App.tsx`                                                                                                                                                                                                                          |
| Пустое состояние / ошибка       | `Empty`, `Result`                                                                                | `Result` уже в 404                                                                                                                                                                                                                                              |
| Загрузка                        | `Skeleton`, `Spin`, встроенный `loading` у `ProTable` и форм                                     | Самописные скелетоны старого UI не нужны                                                                                                                                                                                                                        |
| Статусы                         | `Tag` (цветной), `Badge status=` (точка)                                                         | Словарь «значение → текст + цвет» в `model/labels.ts` страницы (как `pages/clients`)                                                                                                                                                                            |
| KPI-карточки                    | `StatisticCard` / `StatisticCard.Group` (pro)                                                    | Есть `trend: 'up' \| 'down'` для «+12%»                                                                                                                                                                                                                         |
| Деньги                          | `valueType: 'money'` в ProTable, `ProFormMoney` в формах                                         | ⚠ символ валюты: `ProFormMoney` берёт его из локали, `uk_UA` нужно проверить (см. «Где не уверен»)                                                                                                                                                              |
| Даты                            | `DatePicker`, `DatePicker.RangePicker`, `TimePicker` (+ `minuteStep`)                            | Локаль `uk_UA` + `dayjs/locale/uk` уже подключены                                                                                                                                                                                                               |
| Цвет-метка                      | `ColorPicker` с `presets` или `Radio.Group` из цветных кружков                                   | 12 цветов старого UI — как `presets`                                                                                                                                                                                                                            |
| Копирование                     | `Typography.Text copyable`                                                                       | Промокоды, коды сертификатов, телефоны                                                                                                                                                                                                                          |
| Загрузка файлов                 | `Upload` / `Upload.Dragger` + `customRequest` → `POST /uploads`; `ProFormUploadDragger` в формах |                                                                                                                                                                                                                                                                 |
| Просмотр фото                   | `Image` + `Image.PreviewGroup`                                                                   | Галерея визита с полноэкранным просмотром                                                                                                                                                                                                                       |
| Выпадающие меню                 | `Dropdown` (строка таблицы — «…»), `TableDropdown` (pro)                                         |                                                                                                                                                                                                                                                                 |

| Шаг сетки 5 / 15 / 30 / 60                    | `Segmented`                                                                                                                                                                       |

| Выбор сотрудников                             | `CheckCard.Group` (pro) или `Checkbox.Group`; кнопки «Усіх», «Очистити»                                                                                                           |

| — дата, время                                 | `ProFormDatePicker`, `ProFormTimePicker` (`minuteStep`), или `ProFormTimeRangePicker`                                                                                             |

## 3. Чего не хватает в antd и ProComponents

| Что нужно                                                                                         | Где                                | Почему не antd                               | Предлагаю                                                                                                                                                           | Уверенность |
| ------------------------------------------------------------------------------------------------- | ---------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| **Календарь-планировщик**: колонки мастеров, шкала времени, слоты, линия «сейчас», неделя / месяц | Розклад                            | `antd.Calendar` — только сетка месяца / года | `react-big-calendar` 1.20 (MIT, React 19 в peer deps): виды day / week / month, `resources` = колонки мастеров, `step`/`timeslots` = шаг сетки, аддон drag-and-drop | ⚠ см. ниже  |
| **Графики**                                                                                       | Фінанси, Звіти, KPI сотрудников    | В antd графиков нет                          | `@ant-design/plots` 2.6 (MIT, та же экосистема, берёт тему antd) или оставить `recharts`                                                                            | ⚠ см. ниже  |
| **Маска телефона** `+380 (XX) XXX-XX-XX`                                                          | Клієнти, запись, сотрудники, салон | У `Input` нет масок                          | `react-imask` 7.6 (MIT) — обёртка вокруг `Input` + проверка формата в `rules`                                                                                       | уверен      |
| **Командная палитра `Ctrl+K`**                                                                    | Глобальный поиск                   | Нет                                          | Свой: `Modal` + `Input` + `ProList` + горячая клавиша (`useEffect` на `keydown`, ~60 строк). Отдельную библиотеку (`cmdk`) не тянем — её стили не совпадают с antd  | уверен      |
| **Кольца загруженности дня**                                                                      | Мини-календарь                     | Нет готового                                 | `Calendar fullCellRender` + маленький SVG (3 дуги) — ~40 строк                                                                                                      | уверен      |
| **Недельный график работы** (7 дней × часы × перерыв)                                             | Сотрудники, салон                  | Нет готового                                 | Свой компонент на `Table` + `Switch` + `TimePicker.RangePicker`, в `widgets/`                                                                                       | уверен      |
| **Горячие клавиши** (`Alt+N`)                                                                     | Оболочка                           | Нет                                          | Свой хук на `keydown` (~20 строк)                                                                                                                                   | уверен      |
| **Скачивание blob** (экспорт Excel)                                                               | Клієнти, Фінанси                   | Не задача UI-библиотеки                      | Хелпер в `shared/lib`                                                                                                                                               | уверен      |
| **Работа с правами по ролям**                                                                     | Везде                              | Не задача UI-библиотеки                      | Хелпер в `shared/auth`: `canEdit`, `canSeeContacts` по роли из `/auth/me`                                                                                           | уверен      |

### Календарь: почему не уверен и что сравнить

Это самое рискованное место: от планировщика зависит главный экран.

| Вариант                            | Плюсы                                                                                                                         | Минусы                                                                                                                                                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `react-big-calendar`               | MIT; есть `resources` (колонки мастеров) в дневном виде; drag-and-drop аддон; зрелая библиотека                               | ⚠ не проверял, как `resources` выглядят в недельном виде и насколько удобно стилизовать под antd (у библиотеки свой CSS); тип «запись без мастера» — отдельная колонка-ресурс, должно работать, но не проверено |
| FullCalendar (`resource-timegrid`) | Самый мощный планировщик с ресурсами                                                                                          | Плагины с ресурсами — **платные (premium-лицензия)** для коммерческого использования; версии `@fullcalendar/react` 7.x и `resource-timegrid` 6.x сейчас разъехались                                             |
| Schedule-X                         | MIT, современный                                                                                                              | ⚠ не уверен, что колонки-ресурсы есть в бесплатной части                                                                                                                                                        |
| Свой на CSS Grid + `@dnd-kit`      | Полный контроль, выглядит как antd, старый UI уже содержит логику (раскладка пересекающихся записей, перерывы, линия «ЗАРАЗ») | Больше кода: неделя и месяц, скролл, drag-and-drop — всё своё                                                                                                                                                   |

Предложение: сделать прототип дневного вида на `react-big-calendar` (мастера колонками + «Без майстра», шаг 15 минут, линия «сейчас», клик по слоту, кастомная карточка записи). Если стилизация под antd или неделя с ресурсами окажутся неудобными — свой компонент на CSS Grid по логике старого UI.

### Графики: почему не уверен

- `@ant-design/plots` (G2) выглядит родным для antd, но он тяжёлый. ⚠ Не мерил, сколько он добавит к бандлу;
  проверить сборкой. Для админки за логином это, скорее всего, допустимо.
- `recharts` легче и знаком по старому UI, но цвета и шрифты под тему antd (включая тёмную) придётся
  прокидывать вручную через `theme.useToken()`.
- Решать при первом разделе с графиками (дашборд Фінансів).

## 4. Где не уверен

Все места с пометкой ⚠, чтобы проверить до реализации:

1. **Календарь-планировщик** — выбор библиотеки (раздел 3). Нужен прототип. **Не начато.**
2. ~~**Графики**~~ — решено (2026-09-23): `@ant-design/plots`. Весит ~1,2 МБ (≈350 КБ gzip), но живёт
   только в чанке страницы «Фінанси» и грузится суперюзеру при её открытии; основной бандл не растёт.
   Условие — `"sideEffects"` в `package.json`, иначе сборщик тянет графики в общий чанк.
3. **ProComponents 3 — beta.** На страницах `web/` проверены в деле: `ProLayout`, `PageContainer`
   (с `tabList`), `ProTable`, `ModalForm`, `LoginForm`, `ProList`, `ProCard`, `StatisticCard`,
   `ProFormList` и поля `ProForm*`. Работают, но с оговорками — см. раздел 5. Не использовались пока
   `DrawerForm`, `ProDescriptions`, `LightFilter`, `QueryFilter`, `CheckCard`, `EditableProTable`.
4. ~~**Символ валюты**~~ — обошли: `ProFormMoney` не используем, суммы в формах — `ProFormDigit` с
   суффиксом `₴`, в таблицах — `formatMoney` (`uk-UA`).
5. **Сворачиваемые группы услуг в выборе записи.** `Select` показывает группы, но не сворачивает их;
   если это важно — `TreeSelect` с `treeCheckable`, но у него хуже поиск и отображение выбранного.
6. **`Calendar fullCellRender` в свёрнутом меню.** Мини-календарь в `ProLayout` нужно прятать при
   свёрнутом меню; не проверял, как `menuExtraRender` ведёт себя при свёртке.

Отмечу также, что `List` в antd 6.6 объявлен устаревшим (заменён на виртуальный `Listy`), поэтому
для списков берём `ProList`: в ProComponents 3 он не зависит от `antd.List`.

### Подводные камни antd 6 / ProComponents 3

- **Даты в `ModalForm`.** По умолчанию ProForm превращает значения `DatePicker` в строки (`dateFormatter="string"`),
  а время у `TimePicker` внутри `ProForm.Item` — тоже в дату. Для форм с датой-временем ставим
  `dateFormatter={false}` и форматируем сами через пояс салона (`fromPickerDateTime`).
  Без этого форма молча не отправлялась.
- **`initialValues` ProForm** принимаются только при инициализации: значения «по умолчанию сейчас»
  фиксируем `useMemo` на момент открытия, иначе предупреждение в консоли.
- **Бандл.** Чтобы библиотеки страницы (графики) не попадали в общий чанк, в `package.json` указан
  `"sideEffects"`: роут импортирует и запросы, и компонент страницы через один `index.ts`.
- **Устаревшие API antd 6**, которые ловит линтер (`@typescript-eslint/no-deprecated`): `List` → `ProList`
  (или `Listy`), `Space direction` → `orientation`, `Modal destroyOnClose` → `destroyOnHidden`,
  `Statistic valueStyle` → `styles.content`, `Alert message` → `title`, у `ProCard` нет `bordered` —
  `variant="outlined"`, `AutoComplete filterOption` → `showSearch.filterOption`.
- **`StatisticCard trend`** окрашивает «вниз» в зелёный (китайская конвенция) — для отрицательной прибыли
  задаём цвет явно.
- **Предупреждения ProComponents** иногда выводятся на китайском вместе с английским — это не ошибка.
