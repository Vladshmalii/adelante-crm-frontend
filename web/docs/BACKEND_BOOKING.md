# Бекенд и бот: доработки для сайта записи

ТЗ от 2026-09-29. Сайт записи живёт в `web/` как публичный раздел `/booking` (без входа):
`/booking` — список салонов, `/booking/{slug}` — запись, `/booking/{slug}/review?token=` — отзыв.
Ссылки бота и напоминаний (`ADELANTE_BOOKING_BASE_URL/{slug}`) уже ведут туда — менять не нужно.

| #   | Задача                                            | Где              |
| --- | ------------------------------------------------- | ---------------- |
| 1   | Публичный список салонов                          | Booking API      |
| 2   | Ссылки на запись новому пользователю при `/start` | Бот              |
| 3   | Deep link из сайта записи в бота                  | Бот (желательно) |

## 1. Публичный список салонов

Страница `/booking` без slug показывает салоны сети. Сейчас список со ссылками есть только в
`GET /api/bot/salons` (по API-ключу бота) — сайту он недоступен.

`GET /api/booking/salons` — без аутентификации:

```jsonc
[
  {
    "slug": "adelante",
    "name": "Adelante",
    "city": "Київ", // из «Налаштування → Салон», может быть null
    "address": "вул. …", // может быть null
    "phone": "+380…", // может быть null
    "description": "…", // может быть null
  },
]
```

- Только активные салоны (`status = active`), по имени.
- Поля — snake_case, как во всём Booking API.
- Путь не должен конфликтовать с `/api/booking/{salon_slug}/…`: `salons` — зарезервированное слово,
  салон со slug `salons` создать нельзя (или вынести в `/api/booking-salons` — на выбор бекенда,
  описать в ответе).

## 2. Бот: ссылки на запись новому пользователю

Сейчас при `/start` пользователь, которого бот не знает (ещё не поделился контактом), получает
«Щоб я вас впізнав, поділіться своїм контактом… Записатися можна на сайті» — **без ссылки**.
Клиент, который пришёл в бота не с сайта записи, должен сразу получить, куда записаться.

- В этой ветке `greet` после текста отправлять `send_booking_links` (как у клиента и после
  неудачной привязки контакта).
- Текст оставить про контакт: «Поділіться контактом, щоб отримувати нагадування про візити».

## 3. Deep link с сайта записи (желательно)

После записи на сайте кнопка «Нагадування в Telegram» ведёт в бота:
`https://t.me/<бот>?start=<slug>`. Бот получает `slug` в `/start`:

- если пользователь не привязан — просит поделиться контактом (как сейчас), а после привязки
  подтверждает: «Нагадування про візити в салоні <name> увімкнено»;
- если привязан — отвечает, что нагадування вже увімкнені, и показывает ссылки на запись;
- неизвестный `slug` — поведение как без параметра.

Имя бота фронт берёт из рантайм-конфига (`TELEGRAM_BOT_URL`), по умолчанию
`https://t.me/AdelanteCrmBot`.
